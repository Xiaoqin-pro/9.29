# 9.29：三维动态无人机路径规划基础模型

这是在老师胎儿心电项目的简单 MATLAB 风格基础上建立的三维无人机订单路径规划底座。

## 当前问题模型

- 单架无人机、单仓库；
- 从 Solomon RC101 的 100 个客户中固定抽取 20 个二维位置；
- Gaussian 三维地形；
- 8 个圆柱体建筑障碍物；
- 订单高度为当地地形高度加服务高度；
- 单目标订单访问顺序优化；
- 硬时间窗：提前到达可以等待，超过 `due` 的路线不可行；
- 一个动态新增订单事件；
- 事件发生后允许无人机从当前三维位置立即改航，所有未完成订单重新参与排序；
- 最大爬升/下降角、最大水平转向角硬约束，以及轻权重的轨迹平滑目标；
- 当前只使用标准 PSO 作为基础算法。角度约束属于三维路径模型的运动学可飞行性约束，不是 PSO 改进。

RC101 只提供订单二维空间位置，三维高度、地形、障碍物、服务时间和动态时间窗由当前 UAV 模型定义。当前问题更接近带时间窗的动态单无人机订单排序与三维航迹评价，不包含容量和电量约束。

## 标准 PSO 的编码方式

PSO 本身是普通连续粒子群算法。每个客户对应一个连续位置值，按照位置值从小到大排序，排序结果就是订单访问顺序：

```text
连续粒子位置
    ↓ 排序
订单访问序列
    ↓
三维航迹与时间窗评价
```

这种表示方法通常称为 random-key encoding，但当前算法名称只称为：

```text
Standard PSO
```

动态事件发生后，重新调用同一个 `PSO.m`，不保留旧种群信息。这只是动态执行策略，不是另一种 PSO 算法。

```text
                        事件后允许立即改航

```

## 三维几何与角度定义

`Plan3DPath(from,to,model,initialDirection)` 显式接收起始方向；从仓库或已完成服务的客户起飞时传 `[]`。

- 每段爬升/下降角为 `atan2d(abs(dz),水平距离)`，最大允许值为 25°。
- 相邻飞行段的水平转角最大为 120°；飞行中改航还检查事件前方向与新路径第一段的转角。
- `state.direction` 是事件时的三维单位方向。等待、服务和完成订单后视为悬停，允许重新调整航向，方向为 `[]`。
- 平滑度使用归一化水平转角平方和，加上带正负号俯仰角变化的平方和。爬升与下降不会混为同一个正角。
- 可行路线目标为 `distance + 0.05*waiting + 2*smoothness`。角度超限会记录违规并加大罚值，不视为可行。

越障候选按照爬升角计算所需水平距离；水平距离不够时只能达到较低高度，并再次检查净空/碰撞，不能强行截短坡道却仍宣称可行。直线被多个圆柱挡住时，以阻挡圆柱的整体范围构造两个侧向航点，也可沿侧向路径爬升越障。候选越出地图时不参与选择。

25°和120°是当前仿真的规划假设，不是某款无人机的通用物理极限。此处约束的是折线几何，未加入转弯半径、角速度、加速度、推力或六自由度动力学；转角受限不等于曲线/动力学连续。安全检查仍采用每段30个采样点。

当前规划器只比较有限候选，不保证为任意节点对找到全局可行航迹；若所有候选均不可行，返回带违规指标的候选，由 `Fitness` 判为不可行。初始与事件后任务不同，不能直接把两条代价曲线当作同一问题的算法对比。


当前版本的目标是让老师先检查：问题定义、三维航迹评价、动态执行语义和标准 PSO 底座。后续算法改进不放在这个基础版本中。

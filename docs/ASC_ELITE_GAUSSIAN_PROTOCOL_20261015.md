# ASC精英引导稀疏探针：A0–A3运行前协议（2026-10-15）

目标：在原ASC_NoFarness上检验少量受保护的精英探针，不重新调Jump，不加Q/GNN或多算子调度。用户提供的文献描述用于提出假设，不在本批宣称高斯/多精英本身原创或已充分查新。用户提到的远端分支未在本地验证；本批不覆盖原文件，也不依赖另一个环境的授权声明。

## 四个条件（最终冻结定义）

A0：原ASC完全等价路径；无探针。
A1：从真实评价的前20% pbest中均匀抽一个锚点，5维等方差均匀探针（sqrt(3)*U[-1,1]）。
A2：以轮初gbest为锚点，5维标准高斯探针。
A3：与A1相同的多精英锚点选择，5维标准高斯探针。

前述讨论将A1口头称为随机局部探针；最终改为与A3共用锚点、匹配噪声方差的均匀对照，以单独隔离分布差异。A2/A3使用相同高斯公式，只区别锚点来源。各方法使用相同配置的独立探针随机流；轨迹分化后锚点内容自然不同，不能声称以后提案仍逐点配对。

候选y=e，随机5维S置y_S=e_S+sigma*(ub-lb)_S*z，sigma按真实FE进度从.05线性降到.005，原ASC clip边界不变。每第5轮保护1个真实评价名额，替代原几何sel的最后一个名额（原quota至少1）。没有额外评价、没有多探针、没有重新训练。

选择轮初真实历史精英之外、且原几何sel尚未评价的父代中pbest最差者承载。N50、elite10、每轮quota<=10，故存在至少30个未选非精英；载体不接受同轮普通实评，父代cap2不变。正常几何虚拟移动仍先执行；探针失败时保留该虚拟位置，只有探针改善载体pbest时才写入pop/更新pbest/速度归零。所有方法保护global历史档案。原cost(i)可能不对应当前虚拟位置，因此不把它当作当前位置适应度比较；接受参考是载体真实pbest。此批没有SAQ旧版强制再播种/pbest重置，不混称完全相同机制。

探针在普通候选生成和原筛选之后生成并安排，原搜索RNG不因探针生成直接消耗；探针改善后继轨迹与Jump触发可能变化，这是效应而不是保持轨迹相同的保证。原Jump开关、比例、触发、原rank-sum、自适应概率/半径、N50和所有非探针参数不变。可选group/OBL/gaussBest在本批均关闭；本候选不兼容额外启用这些功能，不同时修默认关闭的分组路径以免改变研究范围。

## 预检/审计

A0与原ASC的evaluation points、Best、T、全局RNG状态和原RoundLog前15列完全等价（合成尾预算、CEC、完整100k）。A1/A2/A3每轮恰好quota，tail预算严格，probe总FE等于floor(rounds/5)，探针不能被几何筛掉、实际记录在被调用点；实际父代cap2，载体非精英/未被普通sel评价。pbest和global档案只用真实值，重评所有探针点/最终Best单列审计调用。候选公式和probe RNG独立重放，失败不写回载体、成功更新位置并速度归零；同一配置重复可复现。A0参数不同不应消耗probe RNG或影响普通轨迹。

## 预先开发筛查

分别报告A1/A2/A3对A0以及A3对A1/A2，共5对×8函数=40项双侧配对Wilcoxon+Holm，10seed仍是开发筛查；无零差/并列的双侧精确检验最小P=.001953125，高于40项Holm首项阈值.00125，因此此规模不适合宣称全族校正后逐函数显著优势，不将均值胜称显著。
A3进入独立确认需：对A0至少5/8函数均值更好且函数均值比中位数<=.95；对A1、A2各至少5/8函数均值更好且中位比<=1；F6/F9/F24/F27每项退化<=10%；任一函数退化<=20%。若A2有效但A3不胜，不能宣称多精英必要。失败保留所有数据，停止本批，不改频率/维度/尺度或按F编号选择算法。通过才另行新种子和完整29函数确认。

必须同时报告mean/std/median、配对seed胜负、效应量、完整8函数曲线、每run探针FE/接受/载体和全局成功率，以及probe后改善的观察性诊断（不是单点因果归功）。不能把随机/gbest比较的收益全部归高斯；频率/承载/接受条件本身亦有机会成本。原文件与论文不改。

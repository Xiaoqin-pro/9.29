# CSO骨架删减结果与决策（2026-10-12）

## 已完成范围
D50，F1/F3/F6/F9/F12/F13/F22/F30，三个新seed，100k/500k，B10/SMP3/NoSeekingElite，144次新开发运行，4个process worker。实际预算内目标调用43,200,000次；144次额外Best重查单列；六次smoke单列。全部运行已结束，没有正在运行的优化任务。

默认共同入口通过86组原B10逐点/轨迹/RNG回归，240行为检查、3日志中性、2删减见证。144份MAT又独立通过CSV/真实FE/单调轨迹/逐轮global改善计数/增益望远镜求和/共享初始种群核对。没有域外、预算或Best一致性错误。

## 按先写协议的决策

SMP3在500k通过开发选择门；100k的配对seed11/13未达到12/24不差，所以两预算门**未通过**。NoSeekingElite两预算均未过质量门。原B10因此保留为正式锚点，没有将门限事后改成“只要均值漂亮就通过”。

同时，SMP3两预算多数函数均值更好且时间少约三分之一，100k配对胜负只差一个run达门槛。合理后续是保留原样SMP3作独立确认对象，而不是判它毫无价值，或添加机制救它。三seed下均值与逐seed方向不一致正是需要确认的原因。

下一项建议：先D50/100k、同八函数、10个新seed、B10与原样SMP3，共160次独立确认；不调SRD/CDC/精英项、不合并NoSeekingElite，不先让Q补偿未确定的骨架。确认预写规则要同时报告均值、配对差、排名与速度，并明确这仍是骨架选择。100k主线成立后，标准500k与D100正式验证在方法锁定后追加。本轮没有自动启动这160次确认或配额Q实验。

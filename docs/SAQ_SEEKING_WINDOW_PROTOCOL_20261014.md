# Seeking窗口算子切换：运行前协议（2026-10-14）

用户同意Q直接切换Seeking常规搜索/脱困搜索，要求简单。此候选只改变动作影响范围和脱困候选生成；不增加反向学习、年龄覆盖、第二个Q或重新调奖励。

## 方法和假设

- 固定6T/4S，N50，原Tracing、普通Seeking、几何筛选、cap2、真实记忆/虚拟位置规则不变。
- 动作0：普通Seeking。动作1：在整个100FE窗口中，将每个Seeking父代的4个新候选替换为从当轮gbest出发的单坐标高斯扰动。sigma=1-0.9*progress、边界反射，沿用原探测公式；不追加1个保护探测或强制再播种。
- 脱困候选与普通候选使用同一几何筛选和贪心接受，保持算子选择的单因素对照。它不承诺解决所有几何筛选覆盖问题。
- 普通候选照常生成（保持普通搜索RNG消耗顺序），脱困动作生效时用独立逃逸RNG覆写候选池。候选生成不调用目标函数。
- 状态仍为阶段3×低进展2；1000FE回看、IQR归一化阈值1e-4不变。健康时普通动作，低进展时规则/随机/Q在普通与脱困中选择。动作固定100FE，末轮按真实剩余预算截断。
- Q奖励沿用上一奖励候选：有效改善+10；低进展且实际评价过脱困候选但无有效改善+0.5；否则-1。alpha .1/gamma .9/epsilon .1不变。+0.5是先验塑形，不是真实改善。
- 为最大限度保持旧候选等价，决策仍位于该轮普通候选生成与配额分配后；决策立即作用于当轮Seeking池，后续轮继承动作到下次决策。

## 顺序和规模

D50、100k真实评价、F1/F6/F9/F13/F21/F22/F27/F30、种子8101–8110、4 worker、共享相同初始化/搜索/策略/逃逸种子。已知开发集合，不能称独立确认。

1. 合成正确性检查：普通版与Fixed6逐评价等价、实际调用/尾预算、边界、候选单维结构、真实成本/个人最优、无差时拒绝、Q更新重放与终端处理。
2. 机制阶段：base与rule各80次，共160新运行。base逐轨迹与旧Fixed6缓存再核对一致。规则相对base需至少5/8均值胜、函数均值误差比中位数<=.95；F1/F13/F30至少2项不退化，任一不超过20%退化。未通过则不展开Q阶段。
3. 调度阶段（仅机制通过后）：random和q各80次，另外160新运行。Q相对base至少5/8均值胜且中位比<=.95；相对rule与random分别至少5/8均值胜且中位比<=1；健康函数条件同上。任何负面都保留，停止本批奖励/半径/阈值调参。
4. 通过后才考虑独立新种子确认。原冻结算法与论文不变。

每run独立计数真实优化调用，另计运行后best/全群体/pbest复核。记录每个实际脱困评价的基点、扰动维度、候选、成本、是否改善；完整MAT和运行前源码/CEC哈希冻结。规则的优势不等于Q的优势。

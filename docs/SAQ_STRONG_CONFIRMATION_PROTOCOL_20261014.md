# 29函数强对照确认实验（2026-10-14）

用户要求：10个种子，29函数，与本地强者比较，删除原始CSO和CLPSO。

- 问题：CEC2017 F1/F3–F30，D50，每次100000真实评价，4个MATLAB Processes worker。
- 新方法：ELS-Q、ELS-Replace（规则）。搜索公式、状态、奖励、半径及阈值保持刚完成的开发版，不按函数改参数。
- 对照：HIDMS-PSO-IndexCorrected（作者代码适配，40粒子），DMS-PSO-SIS2005（论文重构，30粒子），HCLPSO-AuthorSource（作者代码适配，50粒子），HPSO-TVAC-CEC（50粒子），SPSO-2011-OfficialC（40粒子）。内部参照：原冻结SAQ-CSO（50粒子）。保留各已审计实现的种群设置。
- 确认种子固定3001–3010，来自既有正式30种子数据的预先选定前10个；新方法开发使用的是8101–8110。这不是完全未见的基准，只是新方法尚未使用的确认种子。
- 每个函数/种子使用已有正式实验的InitSeed/SearchSeed；初始50粒子池由MATLAB twister生成，小种群使用同池前缀。新Q与规则使用共同的独立policy/probe流种子。
- 六个已完成参照方法共1740次缓存：逐MAT核对键、曲线、实际FE、初始化前缀、源码快照；MATLAB重新生成p0、重算每个初始点及最终解后方可复用。所有运行后检查单独计数。
- 新增两方法共580次、58M优化评价；总比较表2320次，其中1740次明确标为复用。旧对照与新方法使用同种子、同初始化协议和同CEC目标，不拼接开发种子8101–8110。
- 运行前冻结新源码、全部所需CEC数据、配置与580任务清单；运行中独立计数目标调用，记录边界、最优档案、真实fitness/pbest检查，保存T与完整终态MAT。
- 统计：逐函数Mean±SD、配对Wilcoxon和同族Holm、函数平均秩；不跨函数平均原始误差。区分原8个开发函数与21个未参与本轮开发的函数。
- 诊断：10k/20k/40k/60k/80k/100k误差比，末20k有效改善，真实位置多样性与探测/动作记录。曲线差距只能指出阶段，不能单独证明局部最优或唯一因果。
- 该轮是10种子确认与差距诊断，论文最终30种子规模仍另行决定；原冻结论文数据保持独立。

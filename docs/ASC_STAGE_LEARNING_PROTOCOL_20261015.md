# ASC 分阶段可信榜样学习协议（2026-10-15）

目标：上一批 B0/B1/B2 实验证明，把 Tracing 的学习方向从"只看精英"改成
"自己的真实 pbest + 精英"可以显著提高真实评价的利用效率（Tracing 改善 pbest
的比例 3.97%→8.49%，F1 误差降低约三个数量级），但收益集中在前中期，后期衰减，
且 F3/F4/F17/F29/F27 退化。本批检验这个机制的**使用时点**，不再调整它的强度。

## 四个条件（运行前冻结）

四个条件共享完全相同的搜索框架、几何筛选、Seeking 模型、自适应概率/半径、
Jump、精英池、父代 cap 与 100k 真实评价预算。

| 版本 | 前 50% 真实评价预算 | 后 50% |
|---|---|---|
| C00 | 纯社会学习 | 纯社会学习 |
| C11 | 认知 + 社会 | 认知 + 社会 |
| C01 | 纯社会学习 | 认知 + 社会 |
| C10 | 认知 + 社会 | 纯社会学习 |

两个公式：

    C00/C01 前段/C10 后段：v = w*v + 2*rS.*(e - x)
    认知阶段：              v = w*v + c1*rC.*(pbest_i - x) + c2*rS.*(e - x)

其中 `rS` 来自全局随机流，`rC` 来自**独立的** RandStream，`c1 = c2 = 1`。

设计要点：

1. **期望学习权重匹配。** 纯社会公式的期望系数为 1.0/维，认知公式两个系数之和
   为 2、期望总系数同样是 1.0/维。所以对比隔离的是"学习方向被拆开"这件事，
   而不是学习强度变大。
2. **认知随机数隔离。** 社会项的随机数在全局流中的抽取位置与纯社会公式完全相同，
   认知项的随机数来自独立流，不触碰全局流。因此四个条件的全局流消耗模式一致，
   差异只来自位移公式。测试已验证：C01 在切换点前与 C00 逐点一致，C10 在切换点
   前与 C11 逐点一致，C00 与原版 `ASC_NoFarness` 逐点等价（含完整 100k）。
3. **切换不做任何重置。** 切换只改变当前轮使用的位移公式；速度、pbest、Jump 时钟、
   群体结构全部延续，也不人为触发 Jump。
4. 上一批的逐维多精英双角色（B2）没有价值，本批不再包含。
5. 本批的 C11 与上一批的 B1 公式相同但随机流结构不同，因此**不能直接复用上一批
   B1 的数值**；C11 在本批是独立的新条件。

## 新增覆盖诊断（不改变搜索行为）

除了上一批的分支/阶段评价统计，本批另外记录：

- 距上次真实评价超过 50 轮、超过 100 轮的粒子比例（逐轮平均）；
- 每 1000 次真实评价窗口内至少获得一次真实评价的粒子比例；
- 粒子 pbest 位置相对搜索范围的归一化离散度（逐轮平均）。

这些量不消耗目标函数评价、不消耗全局随机数，用于检验"认知项是否让有限真实评价
长期集中在少数粒子上"这一假设。

## 设置

- 函数：F1/F6/F9/F12/F13/F21/F24/F27（主筛查 8 个，与上一批一致）
  + F3/F4/F17/F29（交叉检查 4 个），共 12 个。
- D=50、N=50、100,000 次真实评价（含初始化）、4 个 MATLAB worker。
- 新种子 6201–6210：`InitSeed = 262015000 + fid*10000 + seed`，`SearchSeed = InitSeed`。
- 每条件 120 次运行，共 480 次全新优化 = 48,000,000 次真实调用，不复用任何历史性能样本。
- 认知流种子 = `SearchSeed + 7777777`。
- 所有函数此前都已在其他实验中开发过，本批不声称未见函数泛化。

## 运行前冻结的晋级条件

对 C01 与 C10 分别要求：

1. 主判据（8 函数，vs C00）：≥5/8 函数均值更好，且函数均值比中位数 ≤0.95，
   且 F6/F9 各自退化 ≤10%，且任一主筛查函数退化 ≤20%；
2. 交叉判据（4 函数，vs C00）：≥3/4 函数均值更好，且中位比 ≤1.00；
3. 附加判据（4 函数，vs C11）：≥3/4 函数均值更好，且中位比 ≤1.00。

第 3 条的作用是排除"切换版本只是退化成 C00"的情况：只有当切换版本相对全程认知
版本在未调试函数上确实更好时，才说明它真正缓解了机制本身的权衡。

同时对 C11 vs C00 报告同一组判据作为参照，用于检验上一批的机制效应在隔离随机流
之后是否仍然存在。

统计：3 组比较（C11–C00、C01–C00、C10–C00）× 12 函数 = 36 项双侧配对
Wilcoxon，统一 Holm 校正；另报告 C01/C10 对 C11 的交叉集比较。10 个种子下
最小可能 P 为 0.001953125，高于 36 项 Holm 的首项阈值 0.001389，因此本规模
不可能宣称逐函数显著性，均值胜负只作描述性报告。

## 停止规则

若 C01 与 C10 都未能同时通过上述三条判据，则**不再扫描 30%、40%、60%、70% 等
切换时点**，也不再调整认知系数。下一步只能根据本批的覆盖诊断决定是否值得设计一个
状态反馈机制，或者转向其他方向。

均值/标准差/中位数、逐种子配对胜负、效应量、12 个函数收敛曲线、分支与几何阶段的
真实评价成功率、覆盖诊断的全部指标，以及失败情形的完整记录。原文件与既有论文材料
不改。

# 锚点失配稀疏筛选开发协议（2026-10-14，运行前）

承接30种子稀疏框架消融和后续局部停滞开发。当前证据支持稀疏评价主框架，但几何筛选在F6/F9/F27存在边界；多个后续机制使部分函数改善、部分函数退化。本批只检验一个筛选信号：用真实锚点失配替代老师式远中心分支。

## 固定骨架

- N50、MR .4、每完整轮10真实FE（6T4S）、SMP5、Seeking随机20%维度、父代cap2、历史top20%精英引导、真实锚点接受规则、100FE反馈窗口、1000FE低进展门、单维gbest精英再播种均不变。
- 评价预算、初始种群、普通搜索RNG、probeRNG、policyRNG完全共享。
- 只改变稀疏筛选的“第二支”排序依据，不增加额外评价、不改变候选生成公式。

## 对照与筛选定义

- `Fixed6`：无再播种，原几何筛选。
- `Geometry-Rule`：原几何筛选＋单维精英再播种规则。
- `Anchor-Rule`：第二支由“远群体中心”改为“最大归一化锚点失配”＋同一再播种规则。
- `Age-Rule`：第二支由“最大评价年龄”＋同一再播种规则，用于控制“只是优先评价老父代”的解释。

锚点失配定义为候选虚拟位置与承载父代最近真实锚点的欧氏距离平方；实际实现按未归一化平方距离排序，因为所有候选共享同一维度和边界尺度。Tracing候选以自身真实锚点为基准；Seeking候选以承载父代的真实锚点为基准。近gbest分支保持不变，因此变化是单一筛选分支替换。

## 数据与晋级

D50、N50、100k真实FE、F1/F6/F9/F13/F21/F22/F27/F30、种子8101–8110、4 worker。新运行160次（Anchor-Rule、Age-Rule各80）；Fixed6与Geometry-Rule复用同种子、同初始化、同搜索种子的已核验结果。新旧合并前必须核对配置和种子字段。

开发门：

1. Anchor-Rule相对Geometry-Rule至少5/8函数均值更好，函数均值误差比中位数<=.95。
2. Anchor-Rule相对Age-Rule至少5/8函数均值更好，函数均值误差比中位数<=1。
3. F6/F9至少一个相对Geometry-Rule改善>=10%，另一个不退化。
4. F1/F13/F30至少两项相对Geometry-Rule不退化，且任何一项不超过20%退化。

所有比较按函数均值描述，并报告配对种子的Wilcoxon及全族Holm；未显著不等于等效。通过才扩展29函数×30种子；未通过则保留全部结果，不调阈值、不删除函数、不继续堆Q或额外算子。

## 正确性检查

几何模式必须与旧SAQ_CSO_EliteProbe逐评价轨迹、Best、T、探测日志和轮日志完全一致。Anchor/Age模式必须满足真实调用预算、边界、父代cap2、真实fitness/pbest同步、探测写回和速度重置。每个run的终态best、真实群体、pbest和探测点独立重评，额外调用单列，不计入优化100k预算。

本批只评估筛选信号，不把Q写进主方法，不修改论文冻结稿。若锚点失配不能胜过年龄控制，不能称为新的评价原理。

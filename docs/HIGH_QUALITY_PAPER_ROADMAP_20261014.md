# 高质量论文路线规划（2026-10-14）

## 一、先承认当前论文的核心矛盾

现有材料已经能支持“稀疏评价框架有价值”，但不能支持“Q-learning 是主要增益来源”。

- 30种子、29函数、D50/100k：SpatialSparse-Fixed6 对 FullEval-CSO 为24胜5负，145项Holm后13显著好、0显著差、16未显著。
- 同一消融：SpatialSparse-Fixed6 对 RandomSparse-Fixed6 为26胜3负，Holm后9显著好、3显著差、17未显著；F6/F9/F27是已知边界。
- Q相关比较：Full对Fixed4为17胜12负，对Fixed6为18胜11负，对RandomQuota为13胜16负；145项Holm后均无显著函数。RandomQuota平均排名2.483，完整Q版2.621。
- 29函数、10种子强对照：原规则版平均排名4.724，新Q版5.172；新Q对规则版9胜20负。该批用于趋势诊断，不能替代30种子正式表，但方向一致。
- 四算子Q、位置保留和窗口级动作实验均未通过预设开发门；这些负面结果必须保留，不能删除或改门。

结论：若坚持把Q写成“性能提升的核心”，论文在审稿时会面对直接矛盾。更合理的高质量路线是：**稀疏评价是主贡献，锚点失配是新的筛选原理，Q只在验证后作为可选调度器。**

## 二、推荐的唯一主创新：锚点失配的稀疏评价

### 研究问题

稀疏评价节省真实调用，但CSO中未评价的虚拟位置仍继续参与后续搜索。虚拟位置离真实锚点越来越远时，后续的pbest、全局最优和候选生成可能建立在不完整信息上。老师使用“近gbest＋远中心”选择代表点；远中心代表多样性，但不一定代表“信息最不可信”或“最值得刷新”的位置。

### 机制候选

保留现有稀疏CSO骨架、6T4S、每完整轮10真实FE、真实锚点和几何排序框架。只把“远中心”这一支替换为**归一化锚点失配**：

d_i = ||x_i - a_i||_2 / ||ub-lb||_2

其中x_i是候选的虚拟位置，a_i是该个体最近一次真实评价的位置。Tracing和Seeking的稀疏名额仍按父代cap2分配，但多样性/刷新名额优先给锚点失配最大的候选；另一部分仍保留近gbest候选，维持开发。

第一版只比较一个改动：`近gbest + 远中心` 对 `近gbest + 锚点失配`。不叠加年龄、Q、四算子或额外重启。若这个改动没有稳定收益，就不把它写成创新。

### 为什么它可能比“远中心”更合理

- 远中心只说明空间位置远，可能远在无关区域。
- 锚点失配直接反映“这个个体的虚拟轨迹已经多久没有得到真实确认”。
- 它服务于稀疏评价的核心问题：有限真实评价如何维持可信的搜索状态。
- 它是一个候选生成/评价分配原则，不依赖代理模型，也不依赖额外目标调用。

### 需要防止的过度解读

不能声称锚点失配一定优于远中心，也不能把“失配大”直接等同于“适应度会改善”。必须用同预算、同父代cap、同初始种子的对照验证。年龄是它的直接近邻，因此必须加入Age控制，证明增益不是“更老的父代被评了一次”的泛化版本。

## 三、Q-learning 的正确位置

Q不能继续承担“评价配额控制器”的主贡献。此前的配额Q、覆盖Q、奖励Q和四算子Q均没有通过强简单控制。若仍希望保留Q，建议只在主机制通过后测试一个最小版本：

- 动作：几何筛选、锚点失配筛选（或两动作的混合比例）。
- 状态：3阶段×3停滞状态，沿用老师论文的9状态框架。
- 奖励：窗口内真实全局改善；严重停滞时对实际执行的失配刷新动作给小幅探索补偿，但必须单独报告该补偿是塑形奖励。
- 强控制：固定几何、固定锚点失配、随机切换、阶段规则切换。
- 晋级条件：Q相对固定锚点失配和随机切换至少有5/8开发函数均值优势，且健康函数不显著退化；随后用新种子确认。

如果Q不通过，直接删除Q表、奖励和标题中的Q，不通过改奖励倍率、增加动作或更换状态维度来挽救。这样论文仍有“稀疏评价＋锚点失配筛选”的完整主线。

## 四、分阶段实验计划

### 阶段0：冻结与实现

- 冻结当前30种子结果和论文初稿，不改历史表。
- 实现一个独立入口，只改变候选筛选评分；候选生成公式、Tracing/Seeking分配、真实锚点接受规则和预算保持不变。
- 预注册：函数集合、种子、对照、成功条件、统计方法、是否使用新种子。
- 先做合成测试：同预算、同父代cap2、边界、真实fitness、pbest、全局最优、回退和随机流隔离。

### 阶段1：机制开发（8函数×10种子）

建议函数：F1、F6、F9、F13、F21、F22、F27、F30；D50、100k、4 worker。

对照至少包括：

1. FullEval-CSO（完整评价参考）。
2. RandomSparse-Fixed6（随机筛选）。
3. Geometry-Fixed6（老师式近gbest＋远中心）。
4. Age-Fixed6（年龄控制，用于排除“刷新老父代”的解释）。
5. AnchorDiscrepancy-Fixed6（候选主机制）。

开发门建议：主机制对Geometry至少5/8函数均值更好；F6/F9至少一个改善≥10%，另一个不退化；F1/F13/F30至少两项不退化；任何健康函数不出现超过20%的均值退化。未通过则不进入Q阶段，先分析是否只是F6/F9边界。

### 阶段2：正式消融与主比较（29函数×30种子）

主机制通过后：

- 消融：FullEval、RandomSparse、Geometry、Age、AnchorDiscrepancy；必要时加“AnchorDiscrepancy without near-gbest”确认两支作用。
- 主比较：Original CSO、CLPSO、HPSO-TVAC、SPSO-2011、HCLPSO、HIDMS-PSO、DMS-PSO等已核验强对照。
- 统计：每函数30配对种子、双侧Wilcoxon、全族Holm、Friedman平均排名、效应量；同时报告均值、标准差、中位数和最差种子。
- 预算：D50/100k为当前主设置；补充D100/200k或至少一个低预算设置，避免结论只适用于单一维度。
- 明确报告：本方法不声称全面超过所有强PSO；优势是有限真实评价下的质量-评价折中。

### 阶段3：Q模块的有限验证

只有阶段2的固定锚点失配版本稳定优于Geometry和Age，才运行Q：

- Q对AnchorDiscrepancy、Random、Rule三种控制；
- 同29函数、30种子、同预算；
- 若Q没有显著/稳定优势，删除Q，不作为论文贡献；如果Q只在少数多峰函数上改善，可以作为“可选辅助调度”并明确边界。

### 阶段4：三维无人机配送应用

当前论文只有模型描述，没有current method的正式结果。应用部分应完成：

- 固定地形、仓库、订单、时间窗、威胁区和场景数据来源；
- 同一编码、目标函数和100k真实评价预算；
- 至少30个预定seed或30个场景重复；
- 报告可行率、首次可行FE、失败数、可行解距离/等待时间/返仓时间、约束违规；
- 与FullEval、Geometry、AnchorDiscrepancy、Q版和至少2个基线比较；
- 应用结果不能反向调参，不能只展示最好场景。

## 五、论文主张建议

### 可以写的主主张

1. 在受限真实评价预算下，稀疏评价与真实锚点维护能显著提高CSO的评价效率，相对于同骨架全评价和随机稀疏筛选具有整体优势。
2. 锚点失配反映虚拟搜索与真实反馈之间的信息缺口，作为稀疏评价的候选选择依据，优于只看远中心的空间多样性。
3. 若Q验证成功：学习调度可以在复杂多峰阶段选择几何开发或锚点刷新，但增益有限且不承担全部性能结论。

### 不应写的主张

- 不应写“Q是主要性能来源”或“Q必要”，除非新的独立实验通过强控制。
- 不应写“同FE更快”；CEC目标便宜时，稀疏筛选的CPU开销更高。
- 不应写“保证跳出局部最优”；只能写“在检测到低进展时提供有限的再播种机会”。
- 不应写“全面优于HIDMS/HCLPSO”；当前30种子强对照显示仍有明显差距。
- 不应把UAV模型描述当作已完成应用验证。

## 六、建议的论文结构

1. 引言：有限真实评价预算；稀疏评价的机会成本；虚拟位置与真实锚点失配。
2. 相关工作：CSO、稀疏/选择性评价、代理辅助昂贵优化、RL辅助EA；明确与老师空间筛选和已有代理模型管理的区别。
3. 方法：稀疏CSO框架；真实锚点；锚点失配筛选；可选Q调度；复杂度。
4. 实验：CEC2017主比较、稀疏框架消融、筛选机制消融、Q消融、预算/维度敏感性。
5. 应用：三维无人机配送，可行性优先，再报告距离和时间。
6. 结论与限制：不声称SOTA，明确评价预算和CPU折中。

## 七、立即执行顺序

1. 冻结现有论文、30种子结果和负面实验。
2. 先实现AnchorDiscrepancy筛选，不改Q。
3. 在8函数×10种子上跑FullEval/Random/Geometry/Age/AnchorDiscrepancy五路对照。
4. 若通过，扩展29函数×30种子；若失败，分析F6/F9/F27是否指向“锚点失配不是有效信号”，再决定是否放弃该候选。
5. 只有固定筛选机制稳定后，才重新讨论Q是否保留；Q不通过就从标题、摘要和贡献中删除。
6. 最后完成UAV应用和统计表，再改论文初稿。

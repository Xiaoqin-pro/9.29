# B10模式评价小Q预试协议（2026-10-12）

## 入场证据与冻结内容
固定配额预试120run完成：6T4S最佳统一平均排名1.5，4T6S=2.0，2T8S=2.5；各自最优函数5/2/1；八函数的20/60/80/100%节点最佳配额均有变化。先写动作可调性门通过，仅支持试小Q，不证明可学习性。SMP3质量确认未过，骨架继续B10/SMP5，保留精英Seeking。候选模式MR=.4，不变搜索算子、筛选、接受或真实锚点。

## 方法和控制
每10FE完整轮，动作配额2T8S/4T6S/6T4S。每100FE（十轮）决策一次，尾块50FE仍计入且终端更新。6状态=搜索预算进度三段×上一100FE块有无真实gbest改善；第一块视作无过去改善。动作在候选生成前选择，只使用过去反馈。

奖励仅当前动作100FE块真实gbest改善+1，否则−1。alpha=.1/gamma=.9/epsilon=.1，无调参网格、无塑形奖励、无额外状态。Q在下一个实际决策状态更新，终端无bootstrap；块内若实际配额因候选不足回退，该块不更新Q并单独记数。整个块两模式都受配额控制，因此奖励归属整个配额动作，不把它当仅Seeking动作功劳。

七条件：固定2/4/6、uniform Random、Phase、EpsFixed、Q。Phase使用开发观察的简单规则：前2/3预算4T6S、后1/3预算6T4S。EpsFixed用相同epsilon，利用时最佳统一固定6T4S，探索时均匀三动作。Q同样epsilon，利用时最大Q随机打破并列。独立策略RandStream seed=SearchSeed+3000001，不消耗候选全局RNG。固定三动作必须逐点等价旧固定配额，避免控制基线变弱。

预检需三固定动作逐点Best/T/RNG/评价位置等价、FE与tail检查、日志开关中性、状态因果顺序、奖励锚点对应T、Q转移与终端手工重放。独立Python重放每份Q表、逐块状态/奖励/FE/真实action，核对source hash与数据域；没通过不写效果结论。

## 预写验收
全部条件公开，五seed只是开发。Q必须平均函数排名严格优于Fixed6、Random、Phase和EpsFixed，且分别对四对照至少4/8函数均值不差、至少20/40配对seed不差，无双方>1e-8时Q均值恶化>10倍的函数。才进入新seed确认；不要求每个函数打败每个固定动作。固定4即原B10仍完整报告。门未过则停止扩大alpha/gamma/reward网格，解释决策与反馈问题。

报告三种固定策略的全体排名、Q动作占比、state/action访问、每块真实global正奖励密度、两模式每FE接受/global改善。不能把满足门限当正式非劣或显著优势，不能只比Random或挑弱固定控制。无中途看结果改状态/奖励，后续若需要另一反馈只设一个单因素有界实验另写协议。

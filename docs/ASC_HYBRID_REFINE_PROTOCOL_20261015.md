# ASC 组合机制精修协议（2026-10-15）

目标：上一批 2×2 组合实验把主筛查集做到 7/1、中位比 0.8767，F6（0.442）、F9（0.645）、
F27（0.935）全部改善，增量判据"相对 M1 在主筛查 ≥5/8 且 ≤1.00"也通过（6/2，0.9325）。
唯一未通过的两处是：

- M3 在 F12 上退化 34.6%，超过主判据"任一主筛查函数退化 ≤20%"；
- 交叉检查集 2/2、中位比 1.0029，未达 ≥3/4 且 ≤1.00。

逐函数看，交叉集的问题是 F3（1.540）与 F17（1.036），而 F12 与 F3 恰好是上一批
Seeking 精修实验里 A2 退化最明显的两个函数（1.171 与 1.332），也是"精修候选到
全局最优的平均归一化距离"最大的两个函数（0.026 与 0.115，其余函数在 0.021–0.056）。

同一批数据里 A3（在 pbest 中心的基础上再加 0.25 精英引导位移）在 F12 上只退化
2.7%、F3 上退化 12.0%，明显比 A2 温和。因此本批只替换一个东西：把组合里的
Seeking 精修从 A2 改成 A3。

## 三个条件（运行前冻结）

| 版本 | Tracing 学习 | Seeking 候选 3–4 |
|---|---|---|
| M0 | 全程原社会学习（与 `ASC_NoFarness` 逐点等价） | 原始规则 |
| M3 | 后段认知 + 社会（前 50% 预算用社会） | 围绕自身真实 `pbest` 扰动（A2） |
| M4 | 后段认知 + 社会 | `pbest` 中心 + 0.25 精英引导（A3） |

M0 与 M3 在本批重新运行，以保证三个条件在同一批种子下完全可比；它们与上一批的
差异只应来自新种子。

## 设置

- 函数：主筛查 8 个 + 交叉检查 4 个（与上一批相同）。
- D=50、N=50、100,000 次真实评价、4 worker。
- 新种子 6601–6610：`InitSeed = SearchSeed = 262015000 + fid*10000 + seed`。
- 每条件 120 次运行，共 360 次全新优化 = 36,000,000 次真实调用。
- 切换点 50%、`seekRefineCount = 2`、`eliteGuideGain = 0.25` 固定，不扫描。

## 运行前冻结的晋级条件

对 M4 要求：

1. **主判据**（8 函数，vs M0）：≥5/8 函数均值更好，中位比 ≤0.95，
   F6/F9/F27 各自退化 ≤10%，任一主筛查函数退化 ≤20%；
2. **交叉判据**（4 函数，vs M0）：≥3/4 函数均值更好，中位比 ≤1.00；
3. **增量判据**：M4 相对 M3 在主筛查 ≥6/8 且中位比 ≤1.00，且在交叉集不差于 M3
   （中位比 ≤1.00）。

同时报告 M3 在本批种子下的结果，用于确认上一批的结论可复现。

统计：3 组比较 × 12 函数 = 36 项双侧配对 Wilcoxon，统一 Holm 校正。

## 停止规则

若 M4 未通过，则不再调整精修候选的生成公式，转为按主判据与交叉判据分别报告两个
候选版本，并据此决定论文最终采用哪一个。

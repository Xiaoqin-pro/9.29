# CSO骨架删减实验协议（2026-10-12）

## 启动前预算修订
用户指出12k太少并要求对齐导师100k设置。逐页核对导师稿件：CEC2017使用D50/D100，标准10000D，受限20%，因此D50=100k/500k、D100=200k/1M。本轮正式优化尚未启动，直接修订为D50的100k/500k；不继续原12k/60k计划。原始CEC2017说明第2.1节要求10000D、51独立run；本轮3seed仅用于骨架开发，正式结果另规划。预检失败仅为测试审计开关残留和浮点精确比较，已修正测试、不改算法轨迹；保留两次启动日志。

## 本轮范围
只执行既定块1，共144次新的优化运行；不自动开展大规模Q参数扫描。4个MATLAB process worker，每worker单线程。现有B10原文件保持原样，三条件均经共同入口ASE_CSO_Simplify执行，默认逐点评价、Best、T和最终RNG必须与原B10严格一致。

- D50、NP50、CEC2017 F1/F3/F6/F9/F12/F13/F22/F30。
- Seed标签1101/1102/1103；InitSeed=20801012+FunctionID*10000+Seed，SearchSeed=InitSeed+1000000。独立于先前FCS的901–905种子。
- 每函数/seed/预算共享初始种群与搜索seed；100k和500k为独立maxFE运行，不截取长预算轨迹冒充低预算。
- B10：SMP5（四新候选），Seeking精英偏移保留。
- SMP3：只将Seeking候选池改为父代+两新候选，仍保持每父代最多两次实评。
- NoSeekingElite：仍SMP5，只将Seeking的0.25精英偏移置零，保留Tracing精英引导、范围扰动、随机调用顺序与其它公式。
- 不合并删减；MR=.4、SRD=.05、CDC=.2、4T6S、几何筛选、虚拟Tracing/真实锚点、回滚、历史精英、衰减惯性一致。两候选会改变随机数消耗与后续搜索轨迹，这是修改候选池的自然后果，不宣称逐轨迹单一位置对照。

## 正确性与保存
初始化和所有真实评价计入预算；额外Best重查一次独立单列。零域外调用、轨迹有限单调、Best一致、真实模式FE之和=预算−50。选中候选父代/槽位对应、每轮名额、最多二访通过运行前审计；审计日志开关不能改变轨迹或RNG。保存不可变源快照、初始种群、完整MAT轨迹与轮级模式反馈；公开完整raw CSV、汇总、配对数据、源manifest、检查结果。计时比较使用相同公共入口与计数器，不直接与先前机器环境的秒数比较。

## 预先约定的解释与选择
本轮三seed只用于开发筛选，不足以证明统计非劣或SCI主张。逐预算报告函数均值胜负、配对seed胜负、函数均值排名、函数误差比中位数/几何均值、配对时间比、各函数所有结果。误差非负，零附近用1e-12作比值稳定项，仅用于诊断而非改成绩。

候选仅作为下一轮骨架的暂定选择：两档预算各至少4/8函数均值不差、至少12/24配对误差不差，函数误差比中位数不高于1.10；任何一个函数均值恶化超过10倍（双方均未达到1e-8近最优时）均作为严重退化提示，不能被总排名隐藏。SMP3还需配对中位运行时间至少降低15%才承担效率简化理由；NoSeekingElite若质量通过可因删掉一个公式而保留，不强求速度收益。未过门就保留B10，不继续加其它机制救候选。

上述门限为开发优先级规则，不是显著性或正式非劣检验。报告真实指标与门限并列，允许发现局部权衡而暂停定版。若两删减各自通过，不直接假设合并也通过，另做一次独立小验证。

# SAQ-CSO 路线复盘与下一步方案

日期：2026-10-14。状态：已有结果复核与新路线设计；新路线尚未完成性能验证。

## 1. 推荐决定

结束当前“全维均匀随机探测＋原贪心接受”的调参，下一条优先路线为：

**固定稀疏评价骨架（6T/4S）＋APSO 启发的单维精英探测＋真实种群替换；算子有效后，由二动作 Q-learning 选择正常搜索或精英探测。**

原始 SAQ-CSO、正式五算法比较、正式稀疏消融及其论文文件继续作为已完成版本保存。新方法另建文件与结果目录。新路线中的 Q 控制探测动作，原版 Q 控制评价配额，二者分别记名比较，不在同一算法中叠加两个 Q 控制器。

核心叙事：稀疏评价节省验证候选的名额；小规模精英探测使少数名额能够验证新区域；Q 根据阶段和实际进展选择使用这些名额的时机。该叙事需要结果支撑，当前只有前一版稀疏框架有正式证据。

## 2. 最新路线具体失败在哪里

使用修正后的 320 次运行：D50，100k FE，F1/F6/F9/F12/F13/F21/F22/F30，701–710 共 10 个种子。

| 相对 Sparse-Base | 函数均值胜/负 | 配对种子胜/负/平 | 探测评价数 | 超过父代次数 | 超过 gbest 次数 |
|---|---:|---:|---:|---:|---:|
| Fixed-Restart | 1/7 | 27/40/13 | 31,680 | 0 | 0 |
| Random-Restart | 4/4 | 32/35/13 | 30,600 | 0 | 0 |
| Q-Restart | 4/4 | 37/43/0 | 33,060 | 0 | 0 |

这些是描述性胜负，未用显著性检验定义“胜”。四方法平均秩为 Base 2.125、Q 2.250、Random 2.375、Fixed 3.250。

源码事实：

- 候选在全部 50 个坐标的完整搜索盒内均匀生成。
- 实评后仍要求优于该父代，才更新真实位置和 fitness。失败候选全部被丢弃。
- 没有对失败探测实施实际替换、pbest 重置或速度重置。
- 修正结果合计 95,340 个探测评价，记录的父代成功和全局成功均为 0。因此尚未观察到一个被贪心规则接纳的探测点，不能解释为成功的种群重启。
- Q 的选择与正常候选生成共享全局随机数流，策略抽样即使随后被强制为正常动作，也会改变后续候选。
- Base/Fixed/Random 也更新 Q，Q 更新使用未屏蔽不可行动作的 bootstrap；现有奖励对正常和重启动作采用不同表达式。

CSV 的预算是算法自报 FE，并带有原运行的轨迹检查和最终解重算；这批原运行没有保存逐评价坐标与真实种群，不能从 CSV 反推完整的因果轨迹。无效的早期重启文件夹继续保持无效标记，不用于本结论。

## 3. 本次独立实现诊断

脚本：tests/diagnose_SAQ_RestartQ_semantics.m。使用 Sphere 与常数目标，D7、N50，独立记录每次目标调用的坐标；不是 CEC 性能实验。

- 禁用所有重启、相同初始种群及搜索种子、1250 FE：Base/Fixed/Random 与原 ASE_CSO_QuotaQ_Compact 的 Fixed6 评价点完全一致。
- 同样禁用重启的 Q 版：0 个重启评价，但 1192/1250 个评价点与 Base 不同；最终 Sphere 值从 Base 的 2.5751 变成 Q 的 3.9926。该小例只验证随机数混杂，不能外推 Q 的 CEC 优劣。
- 常数目标强制允许探测：440 个探测评价、0 个父代成功、0 个全局成功，最优档案不变。候选接受语义仍由静态源码确认。
- 尾部预算检查：请求 52/55 FE 时，实际目标调用为 53/56 FE。100k 的剩余预算整除常规 10 FE 轮，当前正式重启试验没有出现这个尾部场景；新实现仍必须修复这类边界。

不修改当前源码，以保持最新试验源文件的对应关系。下一开发文件须先解决策略独立 RNG、实际调用计数、精确末轮配额与可行动作屏蔽。

## 4. 从曲线区分问题阶段

数据来自现有五方法正式 D50/100k/30seed 结果，仅使用 20k、60k、80k、100k 四个实际观测节点。对照是各函数最终平均误差最小的已选对照，属于事后诊断选择，不能作为在线策略信息。

| 函数 | 现有 SAQ 后 20k 的均值误差降幅 | 观察及设计含义 |
|---|---:|---|
| F1 | 99.32% | 后期仍强烈改善；中期相对 HPSO-TVAC 落后，统一后期重启可能干扰有效收敛 |
| F6 | 34.12% | 持续改善但中后期落后 CLPSO 越来越多，需要检验局部搜索效率与几何 |
| F9 | 31.75% | 20k 已落后 SPSO-2011，之后差距缩小；只在很晚才随机重启未必处理早期问题 |
| F13 | 82.07% | 后期仍明显下降；中期搜索效率值得优先分析 |
| F21 | 4.94% | 后期改善幅度小，可作为有效停滞和新盆地探测的诊断案例 |
| F30 | 85.47% | 后期仍明显下降，作为防止干预伤害健康搜索的对照 |

此前 870 条 Full 轨迹诊断还发现，终点严格无改善时长中位数只有 82 FE；F27 尾段严格更新很多而累计幅度很小。严格“有一点改善即清零”的触发器可能漏掉效率已很低的搜索。

上述误差曲线不直接测量多样性，也不能证明进入严格数学意义的局部最优。需要额外记录真实位置多样性、精英离散程度、普通候选成功率和探测后改善。

## 5. 借鉴 APSO 的具体内容

本地原文：D:/111/Desktop/噜噜/2/Adaptive_Particle_Swarm_Optimization.pdf，第 9–10 页（期刊页码 1370–1371），Figure 7、式 (13)–(14)。作者 Zhi-Hui Zhan、Jun Zhang、Yun Li、Henry Shu-Hung Chung，2009 年 IEEE Transactions on Systems, Man, and Cybernetics—Part B: Cybernetics。

APSO 的 ELS 随机选择 gbest 的一个维度进行高斯扰动，用其余维度保留已有结构。标准差建议随进程从 1.0 降到 0.1。候选优于 gbest 时更新 gbest；否则用候选替换种群中适应度最差的粒子。

借用这一生成与安置思想，不复制 APSO 的全部模糊状态估计和 w/c1/c2 参数机制。本项目按真实评价进度替代原文代数进度，加入稀疏名额内的单点探测和可信记忆同步；因此是受 APSO 启发的适配，不宣称精确复现 APSO。精英高斯学习算子引用 APSO，论文贡献应由稀疏评价集成和调度证据承担。

教师文章的阶段×停滞状态及搜索算子调度可以用来组织说明，但本路线先只保留两个动作，避免一次复制四个算子而无法定位收益。

## 6. 首个开发版本的明确合同

### 6.1 搜索与预算

- N50，MR0.4，Seeking SMP5/CDC0.2、现有精英引导和几何筛选；常规轮配额固定 6T/4S，总预算仍为 100k 真正目标调用。
- 一个 100 FE 决策窗口最多允许 1 次精英探测。探测占原 Seeking 名额之一，其他名额仍按原框架使用；无新增目标评价。
- 从当轮 Seeking 个体中，选真实 fitness 最差且不属于受保护精英的可用个体承载探测。将它从当轮常规 Seeking 评价计划移除，防止后续旧候选覆盖新锚点；没有可用个体或 Seeking 名额时，该动作不可执行。
- 先保护全局最优档案；当前历史前 20% 精英作为既有保护集，不引入新的精英比例。

### 6.2 只增加一个候选公式

令 p=(FE-N)/(B-N)，随机选一个可变坐标 d：

    y = gbest
    y[d] = gbest[d] + (ub[d]-lb[d]) * (1-0.9*p) * Normal(0,1)

其余坐标保持 gbest 的值。尺度 1→0.1 是首个待检验的 APSO 文献设定，不是通过本项目挑选出的最优参数。越界坐标使用反射映射；反射是本项目实现选择，不归因于 APSO 原文。

探测必须绕过常规几何排序获得预留的 1 个真实评价名额。否则检验的是几何筛选能否选中它，而不是算子的作用。

### 6.3 真正写入种群与记忆

实评得到 f(y)，若更好则更新全局档案；同时将承载个体的 pop、realPop、fitness、personalBest、personalBestCost 同步为 y、y、f(y)、y、f(y)，速度置零。即使 f(y) 不优于承载个体的旧值，也执行这一稀疏替换。全局档案保持历史最优。

这是主动再播种，允许个别真实个体变差。为隔离它的作用，保留“相同候选、相同名额、仍采用贪心接受”的机制对照。日志必须记录从哪一位置替换到哪一位置，以及后续搜索是否使用新锚点，不能用生成数代替写入数。

### 6.4 触发与 Q

- 初始门控：过去 1000 真 FE 的改善幅度归一化到窗口起点真实 fitness 的四分位距，低于 1e-4 时判为有效进展不足；四分位距退化时以初始尺度的极小固定比例作数值保护。该尺度避免使用 CEC 已知最优值，避免依赖目标函数加性偏置。
- 这是开发阈值。记录原严格停滞与新进展量，不同时扫描大量阈值。用固定、预先约定的设定判断路线是否值得继续。
- 健康搜索只执行正常动作；进入低进展时允许 Q 选择 A0=正常稀疏搜索、A1=该窗口安排 1 次精英探测。
- 状态初版为三个预算阶段×两个进展状态，共 6 状态×2 动作。真实多样性先作为诊断记录，不加第二个触发阈值。
- α0.1/γ0.9/ε0.1 与 100 FE 窗口沿用现有量级。所有动作按同一窗口的有效全局改善给 +1，否则 -1；不用“选择逃逸动作即奖励”的奖励塑形，也不用正常/探测两套分母。
- 窗口起点先生成普通候选并计算当轮可用 Seeking 名额，再确定可行动作集合并决策；探测若被选中就在该轮执行。日志分别保存请求动作和实际执行动作，禁止把未执行的探测计为学习经验。
- 策略 RNG、探测 RNG、正常搜索 RNG 分离；Q 决策在动作被禁止时不消费搜索 RNG。动作集合受状态和当轮可执行条件屏蔽，bootstrap 与终止更新按可行状态处理。Q 更新仅属于 Q 策略；规则和随机策略不学习。
- 100 FE 的反馈可能漏掉替换后延迟收益。先记录探测后 100/500/1000 FE 的改善，只有观察到实际延迟收益才调整信用窗口；不以先调奖励代替验证算子。

边界注意：单坐标扰动在旋转、强耦合函数上可能效率不足；非贪心替换也可能破坏本来有效的轨迹。这是需要试验回答的问题。

## 7. 分阶段试验，避免重复大规模消耗

### 第一步：实现有效性，不比最终论文性能

在 Sphere、常数目标、平移/缩放后的目标及受控初始群体上检查：无探测策略与原 Fixed6 逐评价一致；策略 RNG 改变不改变正常搜索；实际 FE 计数等于预算；包括预算 50/51/52/55/59/61；边界、全局档案、真实 fitness、pbest 与速度同步；探测失败仍有实际写入；禁用动作正确屏蔽。

在运行前保存源码与依赖哈希、配置、种子清单；每个 run 保存逐窗口与逐探测日志、曲线和终态 MAT。不要只在运行末尾复制源码。

### 第二步：只问算子和安置规则有没有用

开发集合 F1/F6/F9/F13/F21/F22/F27/F30，D50/100k，配对新种子 8101–8105，4 worker。

比较 3 个版本：B0 原 Fixed6；B1 门控单维探测＋贪心接受；B2 同样门控和候选＋真实替换。先跑 120 次、12M FE，完整保留负面结果。初始值、正常搜索随机流、探测流按 run 对齐；分支导致后续搜索差异是机制作用，不要求不同算法全程候选强行一致。

检查探测父代成功率、全局成功率、实际替换次数、替换后 100/500/1000 FE 收益、真实多样性，以及各节点与最终误差。不要用跨函数原始误差求和决定最佳版本。

开发继续条件预先定为：B2 相对 B0 至少 5/8 函数均值更好，逐函数最终均值比的中位数≤0.95；F1/F13/F30 中至少两项不退化。任一健康搜索案例退化超过 20% 则先查触发和轨迹，不直接扩到正式试验。这些是小样本开发门，不是统计显著性标准。

若 B1 与 B2 都无稳定最终收益，停止本算子；若 B2 有效而 B1 无效，才支持真实安置有作用；若 B1 已足够，则保留更简单的贪心版本，不强保留替换。避免为了预设叙事保留无效机制。

### 第三步：在有效算子上比较调度

规则门控、可行状态下随机选择、Q 选择三策略，用同一算子和名额。同配置的规则结果可复用，随机/Q 只在代码与配置冻结后补跑。判定 Q 是否减少有害探测并改善最终值；不要求每个函数都胜，但不将一次均值优势写成普遍收益。

原 SAQ-CSO 和旧配额 Q 仍可作为已完成参考。Q 没有比规则或随机调度更稳时，保留证据边界，进一步调整应由动作价值或信用分配日志支持。

### 第四步：确认与论文

开发通过后，29 函数、D50/100k、30 个预先登记的新种子；与所选主对照保持预算/初始协议一致。正式显著性检验与主论文规模一致。未参与本轮调参的其余函数提供外推检验，但整个 CEC2017 已经看过历史结果，不能称完全未见基准。

需要进一步区分有效精炼和脱困时，可追加 D30/D100 或无人机应用，而非继续在同一个开发子集无限调参。正式主方法变化需要重跑对应消融并更新文稿，不能混用旧版主表与新版算法描述。

## 8. 后备路线与当前未做事项

优先检验单维精英探测及其写入语义。若日志表明坐标探测在耦合函数上长期无收益，再用沿真实精英差分方向的候选替换这一公式；若后期探索有效而早期 F9 仍差，再专门检查精英引导/筛选造成的早期群体收缩。全域反向学习仍可保留为后备候选，但同样须避免全维破坏结构和失败后立即丢弃。

本次未启动新的 CEC 性能试验，未改原优化源码或论文，未上传 GitHub。新增结果来自既有 CSV 复算与实现诊断。该报告给出下一条可验证路线，不宣称这条新路线已经优于冻结算法。

# 全仓库冻结路线建议（2026-10-12）

状态：用户询问“若现在冻结选什么、是否支持”；本文件是建议与证据重排，不执行正式算法冻结，不覆盖README旧冻结入口，不启动实验。

## 明确判断
支持停止无限机制开发、冻结一个简单方法候选并补正式证据；不支持认定现有Q已经是成立的SCI主创新。若保留用户“稀疏评价+Q-learning+CSO”的目标，最合适的候选路线是原B10改进CSO骨架+可信真实锚点稀疏评价+phase×持续停滞小Q分配模式真实FE名额。选现有1000FE持续停滞版作为单一Q候选，不再拼efficiency、半径恢复、source信用、二访FCS或初值−10。保留Fixed6为最重要强固定控制、原Fixed4为成熟历史锚点。

若只问“今天哪一版有最可信的D50诊断精度证据、可不用Q”，优先固定6T4S的同B10骨架。它在多批D50/100k强于Q，但没有完整29函数充分验证；不能宣布整个仓库跨维度/预算绝对最好。原4T6S/B10覆盖29函数更广，是最成熟性能基准。三seedB10-Cognitive有局部潜力，但没有D50/100k十新seed与配额Q完整验证，不替换骨架。

## 单一Q候选如何长得简单
- NP50，MR=.4；原Tracing历史精英引导/惯性衰减、Seeking四候选(SMP5)/范围扰动/SRD.05/CDC.2/精英偏移保留。
- 每轮真实预算10FE；两模式内部沿用近gbest/远中心筛选、Seeking父代cap2；位置与fitness使用可信真实锚点，虚拟Tracing不更新Best。
- 一张6×3表：进度三段×距上次真实gbest改善>=1000FE二值停滞；每100FE决策一次；动作只有2T8S/4T6S/6T4S。
- binary真实块gbest改善+1，否则−1；alpha.1/gamma.9/eps.1、Q初值0，独立策略随机流，真实下一decision更新和terminal0bootstrap；fallback不训练。
- Seeking半径按原(1−p)衰减，不绑定Q动作，不新增模式搜索公式。Tracing也不增认知项。候选数不降到SMP3。

这是有界选路而非最佳精度定论。选择stallQ是因为状态直观接近导师、表仍小、有开发和独立确认完整证据，比最近版本更少附加窗口统计，便于消融。十seed确认时stallQ对旧previousQ函数5:3/seed40:40，1801批4:4/20:20；不说它在所有批都更好（1401开发只3:5/19:21）。

## 外部效果与故事边界
已从L-SHADE比较raw summary复核：原ASE骨架D30/60k三seed函数1:28，D100/60k12:17。不能给这条路线许诺全面SOTA或因追平教师形式就保证SCI。低预算效率/可接受精度是更合理叙事；筛选/锚点为基础，Q只在证据支持的范围内作反馈分配补充。

导师稿件RL在多数函数无显著差别并非问题，但用户论文自己的Q新增收益仍须证明；导师“无RL=Random”不意味着可以省略Fixed6/Phase/EpsFixed。近gbest/远中心明确继承并引用，不能写本人独立几何创新。CSO本身+新控制接口是渐进研究候选，发表新颖性未自动成立。

## 冻结之后真正该做的工作
先停止参数和机制改变，围绕单一stallQ候选、Fixed4/6、Random、Phase/EpsFixed（与已有范围一致）、必要的same-state规则，完成D50/100k完整29函数的独立10seed范围检查。已有所有Q开发多是八函数，不是最终CEC全套证据；不能只选八函数做定稿。

若Q在完整集有清楚范围收益，原样补D50/500k、D100/200k/1M并最终30seed主表；CEC竞赛原始51run说明与论文30run区分。若仍败于强固定，缩小Q主张或与导师商量是否接受稀疏CSO为主、RL为未有效/辅助扩展，不能删Fixed6来制作漂亮消融。

消融用嵌套结构（配额Q依赖稀疏评价）：同改进骨架全评价；稀疏固定4/6；稀疏Random/规则；稀疏旧previousQ；稀疏stallQ。全评价+quotaQ动作失效，不机械填四格。外部CSO/可忠实复现改进CSO/PSO、CLPSO、L-SHADE同预算，NRL未验收不进主结论。D50/100k与对手500k跨预算另列，不能代替同预算主排名。

UAV最后，固定相同实例/编码/目标/预算/初始化/约束判定，先可行率与首次可行FE，再可行解质量/时间；不为某算法调整时间窗。legacy N=60适配先经真实预算/变量映射和correctness检查，当前NP50候选不能直接称已完成应用对照。

## 是否支持
支持现在冻结方法候选、转入完整证据和收缩论文叙事；不支持现在冻结“Q有稳定学习优势”的结论或直接开始包装提交。按已证优化性能今天单一交付宜用同B10骨架Fixed6（D50条件候选），按用户必须含Q的论文目标选stallQ纯配额候选。两种标准须说明，不能编一个“全仓库Q最好”来回避事实。

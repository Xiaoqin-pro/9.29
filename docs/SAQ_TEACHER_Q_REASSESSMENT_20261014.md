## 原文里真正值得借鉴的设计

1. 稀疏评价造成反馈稀少，Q在上层选择搜索算子。老师使用3阶段×3停滞状态，动作是最优引导、同伴学习、高斯扰动、反向跳跃。动作直接改变位置生成方式。
2. 第7页式(18)：全局最优改善奖励+10；否则，严重停滞时选择高斯或反向算子奖励+0.5；其余-1。+0.5是带搜索先验的奖励塑形，不代表发生了真实改善。
3. 第12页w/o-RL是相同算子集合下的随机选择。Table VI为完整方法相对随机选择7显著好、3显著差、18未显著（共28函数）。论文将主要收益归于空间筛选，RL提供互补收益。这里的检验与预算设置不能和本仓库统计票数直接比较。
4. 原文没有证明RL在所有函数上有效，也没有用该表证明优于固定停滞规则。学习其因果设计与机制分工，性能结论仍须来自本项目实验。

## 最小候选与验证边界

固定6T/4S和现有稀疏框架，复用单维精英扰动，不新增反向学习、年龄覆盖、第二个Q或一组新算子。Q只选普通搜索/执行该脱困动作；探索点占既有1个真实评价名额，避免生成后再次被几何筛选拦截。普通候选的几何盲区尚未因此得到全面解决。

第一步仅改变奖励设计：保留现有状态、100FE决策窗、1000FE低进展检测、有效进展定义和学习参数；有效改善+10，低进展且实际执行探测但无有效改善+0.5，其余-1。这是借鉴老师的奖励塑形，不是对老师方法的逐项复现。未执行、不可行动作不得领取探索补偿。奖励塑形可能退化成持续选择探测，不能以动作占比替代性能证据。

比较对象使用相同生成算子与评价预算：旧奖励Q、此奖励Q、随机调度、停滞规则调度；原始无探测骨架用于判断脱困机制本身。先复用开发函数的10种子协议；改善后以相同29函数、新独立种子确认，再决定正式论文版本。开发正结果及确认负结果都保留。

# 固定MR真实模式评价配额预试（2026-10-12）

## 先验与目的
SMP3十新seed确认未过质量门，B10仍为主骨架。本轮仅检查两模式真实FE配额的差异与互补，尚无Q，不修改模式人数比例MR=.4，不改变候选公式或几何筛选，不加搜索算子。

## 配置
D50/NP50/100000FE，CEC2017 F1/F3/F6/F9/F12/F13/F22/F30，五个新seed1301–1305。InitSeed=21001012+fid*10000+seed；SearchSeed=InitSeed+1000000。三个固定动作2T8S/4T6S/6T4S，8×5×3=120个新run。四worker，每worker单线程；smoke F1/F12×三动作、600FE，共六run单列。

src/ASE_CSO_ModeBudget.m从已验证B10共同入口复制，只增加固定Tracing真实配额2/4/6。SMP5、精英偏移、MR、范围扰动、惯性、几何筛选、cap2、虚拟Tracing/真实锚点、rollback不变。Quota4必须逐点复现原共同入口，Best/T/RNG/轮日志一致，原B10独立文件保留。尾预算沿用原规则并记录；候选不足采用统一补位，按实际Tracing/Seeking计数。不同配额会改变选择与后续搜索轨迹，不声称所有方法在所有轮共享相同候选池。

## 检查与记录
初始化全计FE，目标重查单列。运行前覆盖尾预算、quota4等价、审计日志中性、每轮实际配额与候选不足、每父代最多两FE；四worker smoke通过才启动正式批。保存不可变源快照、完整MAT、共同初始群体、T及轮级local/global反馈。独立核验所有120run，不仅核对最后Best。

## 分析和下一步门
报告全函数均值/方差/中位数、三固定配额平均排名、每对函数/seed胜负、FE轨迹节点、各模式每FE局部/全局成功率、每100FE窗口是否有全局改善、时间。多个函数原始误差不能直接相加选最佳；三动作整体最佳由八函数平均排名选择。

先检查是否一个动作在所有函数均值不差且总体配对不少于一半；若这样支配另外两者，先用固定动作，不扩大Q。若至少两种配额分别在至少两个函数均值最好，且至少两个函数显示在20/60/80/100%预算节点的最优配额变化，则作为小Q预试的动作可调性证据；五seed仍不能证明状态可学、阶段互补或Q一定有效。无这类证据则先报告不确定，不硬启动Q。

模式反馈为观测诊断：一个配额影响整轮搜索，Seeking/Tracing的成功率不构成未选择配额的反事实；local成功率与gbest全局贡献分别列出，不将一方高接受率自动当有效控制信号。决策状态只能读取已完成FE窗口。后续Q若进入，另写同动作集Random、Phase和EpsFixed对照协议。

本轮受限100k是主开发尺度，标准500k与D100在方法成立后追加，避免一开始铺开完整参数/预算网格。

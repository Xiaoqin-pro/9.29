# Official CEC2017 D100 input data

Source: [P-N-Suganthan/CEC2017-BoundContrained](https://github.com/P-N-Suganthan/CEC2017-BoundContrained), `CEC17_fast_pow-C++.zip`, downloaded 2026-10-09.

Archive SHA256: `51e7f55dc5cddf263ec128771dee1db6a2d0e2816b3d650160eb51960f269a1e`.

All 60 D100 rotation/shuffle text files were copied byte-for-byte from `CEC17_fast_pow/input_data`. Per-file hashes are recorded in `D100_manifest.csv`. Existing D30 data were retained. All 30 existing shift files matched the official archive byte-for-byte, so no shift file was replaced. The repository MEX and algorithms were not modified for this experiment.

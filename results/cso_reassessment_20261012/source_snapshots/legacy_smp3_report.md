# V1-Elite 的 SMP3 加速对照

## 实验协议

- 函数：F1、F3、F6、F9、F10、F12、F15、F19、F22、F26。
- D=30，种群50，300000 FE，重复21–23。
- 与已完成的 V1-SMP5 使用相同初始种群、InitSeed和SearchSeed。
- Global-Cap2、Range Seeking、MR=0.4、无 Recovery、无 Q-learning。
- 唯一改变：Seeking 候选池由 SMP=5（1个父代+4个候选）改为 SMP=3（1个父代+2个候选）。
- 每轮真实评价仍为5次，其中 Tracing=2、Seeking=3；SMP3 只减少虚拟候选数量。

## 性能剖析

对一条 V1-SMP5、F1、300000 FE 的单运行 profile：

| 函数 | 总耗时（秒） | 调用次数 |
|---|---:|---:|
| GlobalCandidateScreen | 5.02 | 59,990 |
| SelectCats | 1.48 | 59,990 |
| mean 及其内部计算 | 2.57 | 约 540,000 |
| CEC2017 Fitness（含入口） | 1.42 | 300,000 |

筛选和 MATLAB 数组操作的开销明显高于 CEC MEX 本身。SMP3 将平均时间降低约 27%，但本轮没有改善最终精度。

## 当前结论

1. P0 已完成性能定位；目前不改变筛选数学规则，避免因随机数消耗顺序变化破坏已有结果。
2. P1 支持保留 SMP3 作为加速候选，但默认 V1 仍保持 SMP=5，因为 SMP5 在中后期收敛节点略有优势，且最终误差没有稳定差异。
3. 不把 20% FE 直接设为默认。F1、F3、F15 等函数的重要改善发生在后期，低预算需要独立实验。
4. V2-EliteDiff 暂停，不加入新的差分或恢复机制；Q-learning 也暂不重启。

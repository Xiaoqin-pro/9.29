# Pure Range Seeking validation

Protocol: the same 23-function extension set used for the Classic/Hybrid validation, with D=30, population=50, 300000 FE, 3 paired seeds, fixed MR=0.4, no Recovery, and DSS screening.

`DSS-RangeSeeking` uses the range-normalized additive candidate formula. It is compared with the previously saved Classic and Hybrid results using the same function IDs and seeds.

Across the 23 functions, Hybrid is better than pure Range on 7 function means and worse on 16. Pure Range is therefore a strong single candidate pool on this extension set, while Hybrid remains useful on several of the six focused development functions. The three candidate pools are complementary rather than having one uniformly dominant formula.

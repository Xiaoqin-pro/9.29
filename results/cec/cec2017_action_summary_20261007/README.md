# V3 动作消融汇总（开发实验，2026-10-07）

协议：CEC2017 的 F3/F5/F10/F13/F15/F19/F25/F28/F30，D=30，50 个体，300000 FE，开发 seed 1:3。保留 V3 的新机会筛选和父代成功统计，不改奖励与动作参数。本轮不是正式 30 次实验。

## 来源和有效性

| 数据目录 | 搜索随机流 | 本汇总用途 |
| --- | --- | --- |
| `cec2017_v3_20261007_190313` | twister（串行默认） | 复用 27 次旧 V3 的 Q-learning 记录 |
| `cec2017_action_parallel_20261007_204819` | threefry（worker 默认） | 保留 Q-learning/Random/A1/A3 共 108 次有效标签记录 |
| `cec2017_action_missing_20261007_213131` | 显式 twister | 54 次 A2/A4 补跑，动作分支已修正 |

上一批并行脚本传入 `fixed2` 和 `fixed4`，核心算法当时没有相应分支，实际落入默认 A1。两组 54 次记录的动作全部为 A1，不能当作 A2/A4 的结果。原始 CSV 原样保留；`action_audit.csv` 标记 `LabelValid=false`，有效汇总排除这些记录。

另一问题是 `rng(seed)` 在客户端默认 twister、在 worker 默认 threefry。同 seed 不保证相同序列，串行/并行小预算复现检查确认了这一差别。修复提交 `45a90e6` 显式指定 twister。初始化都在客户端产生，本次核对确认同函数、同 run 的初始矩阵一致。

旧 V3 的 Q-learning 在默认 twister 下运行；之后改动为消融开关、诊断记录、固定动作分支和显式随机流，没有改变该配置的搜索公式。故复用其 27 次记录与补跑 A2/A4 作同随机流比较。旧 threefry 数据另列，不与 twister 合为六配置配对排名。

## 文件

- `available_runs.csv`：189 次有效标签记录，包含 `SearchRNG` 与 `SourceDirectory`。
- `summary_by_rng.csv`：按函数、配置、随机流分组的 mean/std/median，63 行。
- `twister_comparison.csv`：Q-learning 与补跑 A2/A4 的同随机流对比，含逐 seed 胜负。
- `action_audit.csv`：243 个源历史文件的动作标签审计，包括 54 个误标历史记录。

所有源历史文件均检查了 FE=300000、历史长度、有限值、单调最优值、边界、初始矩阵以及 Seeking/Tracing FE 总数。补跑的 A2/A4 动作记录分别为 100% A2 和 100% A4。

## 同随机流结果

以下为三次运行的平均最优误差，越小越好；标准差和中位数见 CSV。胜负是描述性比较，不是统计显著性结论。

| 函数 | Q-learning | Fixed A2 | Fixed A4 | Q-learning 对 A4 |
| --- | ---: | ---: | ---: | --- |
| F3 | 1.595 | 11587.7 | 0.859 | 较差 |
| F5 | 213.75 | 216.40 | 108.51 | 较差 |
| F10 | 4822.95 | 6628.07 | 3927.38 | 较差 |
| F13 | 69933.68 | 27053798.64 | 120335.99 | 较好 |
| F15 | 32752.02 | 501598.68 | 66527.86 | 较好 |
| F19 | 395385.92 | 300846.96 | 283426.60 | 较差 |
| F25 | 389.067 | 441.486 | 386.907 | 较差 |
| F28 | 422.059 | 518.627 | 431.813 | 较好 |
| F30 | 1445264.80 | 9238611.83 | 1692230.17 | 较好 |

Q-learning 对固定 A4 为 4 个函数均值更低、5 个更高。其中 F13/F15 的均值分别低约 41.9%/50.8%；F5 高约 97.0%，F19 高约 39.5%。不能声称 Q-learning 全面优于固定 A4，也不能说固定 A4 在所有函数都更好。

另一个独立的 threefry 组中，Q-learning 对 Random 为 1 个函数均值更低、8 个更高，F19/F30 差距较大；每个函数仍只有 3 个 seed，部分均值受离散程度影响。该结果不能与 twister 的 A2/A4 作跨流配对比较。

## 当前判断

固定 A4 是强动作，现有 Q-learning 的增益尚未得到总体证据支持；但 F13/F15 的同流结果说明调度也有局部收益，不能简单归因为“全部收益只来自 A4”。本轮没有改变机会评分、恢复动作或奖励，不能确认这些因素各自的因果贡献。

后续如需完整六配置同流对比，应补齐 twister 下的 Random/A1/A3 共 81 次，而不是把 two-stream 数据拼成六配置排名。3 个开发 seed 不足以作为正式显著性或论文排名证据。

运行时间保留原值供追溯；复用 Q-learning 为串行运行，A2/A4 为并行运行，不能把其 Seconds 比值直接当作调度算法的运行时间优势。

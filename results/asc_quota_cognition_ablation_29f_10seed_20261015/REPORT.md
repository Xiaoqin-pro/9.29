# 2×2 消融：评价配额再平衡 × 认知 Tracing 方向

CEC2017、D50、N50、100,000 次真实评价、29 个函数、种子 3001–3010，
全部算法共享相同的初始种群与搜索种子。

## 两个机制

| 记号 | 改动 |
|---|---|
| 配额 | 几何筛选把每轮十个评价名额分给"近最优"阶段的比例，0.5 → 0.85 |
| 认知 | Tracing 的学习方向在后 50% 预算中加入粒子自身经过真实评价的 `pbest` |

两个机制都只触及一个参数或一条公式，其余（候选生成、Seeking、Jump、自适应概率与
半径、精英池、父代 cap、预算）是冻结的 `ASC_NoFarness` 代码。默认配置
（配额 = 0.5、无认知）与原版逐点等价，测试含完整 100k 的评价点、最优解、
best-so-far 与全局 RNG 状态比对。

## 结论

**配额再平衡是主要贡献。** 它单独把平均排名从 6.155 拉到 4.966，函数均值 21 胜 8 负，
中位误差比 0.8870，且最差的函数退化只有 17.5%。

**认知方向单独也有效**（19/10，配对 193/97），但它的收益与配额再平衡高度重叠：
叠加之后 A3 相对 A1 是 11/18、中位比 1.0021，即没有额外增益。

逐函数看，认知项的贡献与代价都很清楚：

| 函数 | A0 | A1（配额） | A3（配额+认知） |
|---|---:|---:|---:|
| F1 | 5.777e+06 | 5.777e+06 | **6.883e+03** |
| F6 | 9.437 | 3.126 | **1.837** |
| F7 | 3.838e+02 | 4.508e+02 | **1.359e+02** |
| F13 | 6.441e+04 | **5.487e+04** | 1.010e+05 |
| F14 | 7.231e+04 | **5.128e+04** | 7.480e+04 |
| F15 | 1.356e+04 | **1.203e+04** | 2.257e+04 |
| F30 | 1.784e+06 | **1.763e+06** | 2.771e+06 |

认知项把 F1 改善了三个数量级（这正是 ASC 与强基线之间最大的单项差距），并把
F6、F7 进一步压低，代价是 F13–F15 与 F30 的退化。两项相互抵消，所以 A3 与 A1
在整体排名上并列。

对论文的意义：**主机制应当选配额再平衡**——它更简单（只改一个数）、更有效、
退化更小，而且它的动机来自框架自身的诊断（分支级真实收益审计）。认知方向可以
作为第二个机制报告，并如实说明它与主机制不叠加。

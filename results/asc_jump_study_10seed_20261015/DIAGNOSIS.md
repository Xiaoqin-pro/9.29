# ASC Jump实验：诊断与决策

本轮仅修改原文件已有的useJump和jumpFraction，未改筛选、更新方程、半径和概率控制。所有条件共享其余参数、种子与初始化；Jump后随机流消耗自然分化。

## 结果

轻量Jump对原版：6胜2负，中位函数均值误差比0.9586，配对种子45胜35负。关闭Jump对原版3胜5负。轻量版对关闭版8函数均值更好，但不将均值票数称为显著性。

| 函数 | 轻量Jump相对原版的均值变化 |
|---:|---:|
| F1 | -15.53% |
| F6 | -43.66% |
| F9 | +117.55% |
| F13 | -11.84% |
| F21 | -3.56% |
| F22 | -4.71% |
| F27 | -1.10% |
| F30 | +15.14% |

负值代表误差减少，正值代表恶化。

## F9不是一个极端样本就能解释

F9轻量版在10个配对种子中3胜7负。中位误差也由334.0985升至504.1189；均值恶化117.55%。10种子尚不足以证明普遍性，但该信号不能删除或只以均值挑异常值。

## Jump次数与规模

原版平均Jump60.80次、轻量版60.56次；两者频率接近，但每次重置20/4个位置，总重置次数均值分别为1216.00/242.25。这些是事件计数（同一粒子可多次计入），不是独立新粒子数。

## 统计与结论

轻量版相对原版的8个逐函数检验均未通过本24项Holm校正，不能把开发均值优势写成显著优势，也不能把未显著写成等效。
本比较族显著项：F27，LightJump vs NoJump，Holm=0.046875，均值比=0.97055。

预定筛查未通过：F9退化超过20%，且不满足F6/F9各不退化10%的约束；轻量版中位均值比也略高于.95。保留原ASC默认值，不扩大到29函数、不按F编号切换Jump、不继续本批调参。
当前证据更支持“Jump有用，但强度存在取舍”，不支持“Jump必然破坏收敛”，也不支持“一律减小/删除Jump”。
后续若继续研究，应先确认能否用可观测搜索状态区分需要强恢复的过程；无需立即加新评分、Q、概率和半径控制。此方向尚无实现或有效性保证。

## 运行信息

全部240次优化调用严格100k；每次调用的最优轨迹与算法返回T完全一致。11项预检、240条状态/Jump/参数重放和公开CSV复算通过。原文件SHA未变。错误启动在优化前结束；正式计算结束时的哈希表列名读取异常通过独立校验恢复，没有重新跑或选择性删除样本。
